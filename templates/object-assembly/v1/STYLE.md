# 小物装配 · v1

适合家居小物、结构展示、零件落位等低密度设计短片；不承诺工程真实、产品功效或真实物理仿真。不适合人物走路、口型、复杂表演和任意照片直接生成三维。用户给自然语言、对象和结果，由 Codex 编排故事，不要求用户写 JSON。

固定语法：暖色哑光体积、真实几何接触和投影、文楷、先分散后组装、缓入接触后短暂落定、最后绕到侧面观察。标题在上、主体在中、结果字幕在下。9:16 为1080×1920；16:9 为1920×1080，横屏独立排标题和字幕。横屏仅代表帧适配验证，完整新片以竖屏为准。

开放接口是 [example.json](example.json)：`objects` 的形状、尺寸、颜色、初始/结果位置和旋转；`events` 的对象关系、准备/接触/结果/结束整数帧、结果字幕和接触音；`camera` 的三维位置、帧和观看动机；`activation` 为灯光触发帧。支持 box/cylinder/torus/sphere，不接受人物形状。30fps，150–1800帧；标题最多16字，结果字幕最多20字。

自然输入：“做一条抖音竖屏设计短片，让散开的底座、支杆、灯罩依次装成一盏桌灯，最后亮灯并绕到侧面。用实物动作讲清过程，留接触音，不要配乐。”另一份实测输入用三腿花架、花盆和绿植，改变零件数量、支撑关系、事件与镜头，不只改标题。

换稿沿已有入口：`studio.py intent` → `templates match --format 9:16` → Codex结合样片确认ID/版本、赛道/受众/承诺 → 将故事存入新文件 → `--mode development templates prepare <story> --to <新目录>` → `plan <brief>` → `workflow <任务>` → 已授权的 `--mode production make <brief>`。不覆盖父稿；编译目录冻结字体、依赖、故事、音轨和同步表。`make` 同时检查故事、场景、字幕和音轨事件；画面局部修改继续原作品版本，复用原音需保持时序与字幕不变。

复用的是本地 MG03 的 `anim.js` 纯时间缓动与三维材质/光照组织方法，MIT，许可证随工程冻结；Three.js 0.181.2及文楷OFL同包。不是只调用渲染外壳，也未移植他人产品几何、画面、镜头轨迹或音轨。X上的家具组装仅作题材与事件顺序参考，原视频未完整观看，不能声称复刻其视觉效果。详见[本轮研究](../../../docs/research/2026-11-14-两平台与触感模板研究.md)。

阶段：本轮新内容制作与换稿验证；最终确切视频/工程/哈希以[同版检查](../../../productions/tactile-templates-20261113/验证与交付.md)和catalog为准。初版使用本地合成短接触音，已被用户否决并保留。当前四片候选v0003仅返修声音，采用Kenney CC0实录短音，无配音、无BGM；SOURCE.json记录来源与替代关系，桌灯开关为纸卡接触代理音，不冒称真实开关录音。prepare的默认合成配置未自动切换，换稿时需显式选择已核来源的音轨和同步表。程序同步不等于自然听感；真实听审、专业人审、用户认可和平台表现仍待验。
