# 连续墨线叙事

入口为 native/index.html 与 story.json。复用固定 MIT Opuscar 的弧长采样、曲率减速、笔压、纸纹与纸齿；本模板重做叙事、路径和相机，不含原作者人物／老人交棒故事。

换稿必须同时修改 segments 的 SVG 路径、绘制时间、camera、captions 和 ending，按路径的物件意义串起完整主题；只换字不可。每个段落先画轮廓，连接线承担旅程。最后拉远揭示整条线的关系。当前只验证横屏路线；音轨单独供给并听审。

市场形式参照 ink-motif 的墨线母题叙事，工程来自不同作者，不冒称原帖源码；原帖播放／点赞不能移给本片。无旁白的诗性短片允许静音，音乐版必须另验。
