# STORYBOARD

**Logline:**

**Song grid:** 写明 BPM（半拍）、一拍多少秒、一句歌词几拍；剪辑取原曲 a–b 秒，起点在拍点上，末尾淡出 1.8 秒。

**One world / 配色弧线 / 母题 / 首尾呼应:**

**Cast:**（至少两个角色，或一个配角/动物；写清楚谁和谁有互动）

**起承转合:** 起 / 承 / 转（反转或意外） / 合

每个镜头五列都要填，有一列空着就不能开工：
- **主动作**：身体在做事，例如跳、伸手、抛、跑、拥抱、坐下；只有表情变化不算。
- **次级动作**：跟随或重叠，例如帽子、围巾、提灯晚一拍跟着动，或者呼吸、眨眼、配角的反应。
- **氛围层**：从 fx.js 选，例如粒子或光。
- **特效时刻**：放在节拍点上的那一下，例如冲击、心形爆发、光束、扫光、集中线。
- **景别**：远 / 全 / 中 / 近 / 特写。同一景别不连续 3 镜；高潮镜头的景别要和相邻镜头不同。
- **镜头运动**：推、拉、摇、跟、手持、甩镜、固定（固定 ≤ 40%）。

同一个特效不能连着用两个镜头；镜头静止不超过 2 秒；每 8 拍至少出现一个新信息；镜头 2/4/8 拍且 ≤ 4 秒，副歌前逐段缩短。`./vf gate` 会自动查这些。
