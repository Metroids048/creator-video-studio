# 视觉设计与素材

本 Skill 负责视觉决策和素材交接。先沿主 Skill 核本轮阶段、画幅、受众、内容、owner、父版、锁定声音与授权；研究任务交研究，获准制作才生成。具体方法只有一份：[视觉设计方法](references/视觉设计方法.md)。

封面任务另消费[从片内回报到标题封面](../studio-publish/references/内容到封面.md)：从真实动作、物件关系与内容回报提取概念，落实标题分工和120像素缩略图核查；不能只按题材做一张漂亮海报。

1. 用 `studio.py visual-assets` 读取真实目录；按 `--query 纸张` 或 `--recipe causal-diagram` 缩小。第一原片确认的 Motion Prompt / VFX Atlas 也走同一查询，如 `--query 水彩`、`--query 轮廓光`、`--query 颗粒`、`--query "dolly zoom"`。返回定义、数值规格、提示词、选取源码与许可；默认只带库摘要，具体设计时再检索。240项规格与504项效果资料不是已渲染组件，Atlas参考图没有通用再使用许可。消费文件路径、SHA256、用途和限制；外部来源尚未下载就保持缺项。
   需要数据、对比、步骤、引用、标注等包装时，读 `resources/visual-library/README.md`，从 `overlay-components` 的真实 registry 选择公开卡片，沿 `visual-build --engine overlay` 出 PNG 或动效。19种可作透明层；FocusCard 自带全屏底色，可消费本地 `camSrc` 视频。过程图解可用 `--engine table` 的 MIT 连续场景，只支持已声明的三件组件检验关系。用 `visual-compose --material <渲染目录> --background <本地图片或视频> --out <新版本>` 实际合成背景；该入口只处理画面，作品声音沿原锁轨入口。`studio-inputs.json` 含图片/视频与原生 ZIP 绑定，合入本作品既有 inputs 后沿原流程检查。20项实测见 `docs/research/2026-11-17-视觉素材与审美/verification/all20/index.html`。未知卡、远程媒体和不同内容关系先查适配缺口。
2. 把用户承诺变成视觉概念：观众先看见什么、接着发生什么、最后理解什么。参考分别注明借构图、色彩、材质、动作还是信息组织；完整观察范围不足的参考不能当完整复刻基准。
3. 沿方法写本作品的 `visual-direction.md`：视觉概念、参考角色、画幅/小屏层级、字体与色彩、主体/道具/空间、材质/光线、运动规则；逐镜关联资产 ID、实际文件与哈希。已有等价场景合同直接补充，不新开平行台账。
4. 图片先出一个能检验概念的关键画面，实际看主体、层级、中文、材质、身份与裁切。生成走宿主图片工具与项目封面约定，按供应方实际支持传入参考；不抄其他工具专属参数，不为研究调用生成，不静默换供应方。
5. 视频把已选关键画面交给 `studio-motion-design`：外观由画面/素材固定，运动提示说明动作、镜头和状态变化。代码路线直接复用实际字体、SVG、场景与相机。先查最难代表段，再扩完整片；不以装饰颗粒、镜头多或推拉缩放冒充表演。
6. 已有模板可在保留结构与内容承诺下升级资产和层级；模板外方案先交独立视觉方向与代表画面，核现有可编辑引擎能否消费。新建 make 仍沿现有模板资格、stage_handoff 和审片入口，缺适配就明确缺口，不能伪填模板或绕开检查。

交回主 Skill：采用的方向与原因、引用素材、实际关键画面/代表段路径、失败与待验、下一允许动作。目录与配方可读不等于画面变好；同版完整视听、用户反馈和发布数据分别记录。
