# 视觉先于装饰，素材服务内容

适用于图片、封面、原有模板升级和模板之外的视觉开发。模板是整片结构与动作的复用，素材是可组合的具体对象，设计方法决定它们为什么这样组合。三者一起用。两条完整源文件已取得，已逐2秒检查覆盖全时长的画面并读取全音轨离线转写；仍未完成正常速度连续完整视听。第一条原片画面确认 Motion Prompt 与 LetzAI Atlas，第二条确认 Table-VideoSOP。Overlay Studio / motion-explainer 是同作者扩展研究，不能替代第一条实际推荐。

## 先定一个能看懂的概念

用一句话说明“谁/什么对象，在什么状态，发生什么变化，让观众理解什么”。例如“收藏的方法很多，真正执行的只有一项”可表现为一组有出处的资料物件与一个正在改变状态的行动对象；不能只把这句话放大、加颗粒、推近。知识画面要看得出原因、动作和结果，情绪画面要看得出具体处境与反应。

先看具体参考，分别记录内容、构图、字体、颜色、材质、空间/光线、动作和声音的作用。分清身份参考、构图参考、风格参考及事实证据；不要让风格图改掉用户产品、人物或事实。参考页需保留来源、版本和采用原因；对标视频未完整观察时，只使用确已看到的范围。

## 做一张方向板，再决定资产

方向板是本题的有限选择：一个核心画面概念、一组相容参考、主体/背景/信息/强调层、字体搭配、主色与强调色、光向/材质、运动原则和反例。无需凑固定张数；先解决最重要的取舍。一个镜头只应有清楚的注意焦点，颜色、字体和材质在跨镜头中保持同一含义。

字体先按语言、字形覆盖和信息任务选；小屏下读正文、短标题和标注。中文不指望英文字体自动变好。材质必须属于物体、表面或整体语言；纸纹不盖文字，颗粒不掩盖人脸与产品。追求真实时可从合理光向、相机位置、空间层次和受控细节入手，不能一律加脏点或降低清晰度。

素材记录含资产 ID、文件路径/哈希、来源与许可、实际用途、适用画幅/引擎和限制。已有本地材料优先复用；没有本题主物件就补具体照片、透明底对象、图形或必要生成，不用“素材库已齐全”掩盖空缺。网上能看见不等于可以再分发。

## 从图鉴建立自己的视觉语言

一页枝鸥原片约01:46–02:22介绍 [Atlas of Visual Effects](https://atlas.letz.ai/)，约03:04–03:38介绍 [Motion Prompt](https://github.com/showheyohtaki/motion-prompt)。本地已取 Atlas 的504项效果索引、8项详情，以及 Motion Prompt 当前240项定义/提示规格、6项完整提示词、3项预览代码与运动/相机工具源码；原片显示的是较早192项版本。作者自己的HTML图鉴没有找到公开下载，不能将本项目工作台称为作者原项目。

从图鉴选与本题有关的术语，分开记录外观（材质、色彩、光线、媒介）与运动（对象动作、相机、转场、时间曲线）。在现有 `visual-assets --query` 中查定义与具体参数，不用笼统“高级、电影感、史诗”代替选择。Motion Prompt保留原数值、缓动及尺度；所选源码仅3项，不默认240项均已接渲染器。Atlas选中详情返回效果解释、可移植提示词与出处，可接现有图片生成提示；示例图片仍须另核使用权，未调用LetzAI生成服务。

原片的白模方法：先拿掉纹理、花色与装饰，验证主体、动作、相机和信息推进；动作成立后再套已定材质与光线，避免风格遮住动作问题。原片提出以少量风格组合建立个人视觉语言；本项目按本题选择相容的主风格和辅助层，不机械叠满3–5种。跨镜统一色彩含义、材质与角色身份。模板内可只替换本题需要的资产与运动；模板外仍先核最难代表画面或段，缺表演能力不能靠滤镜弥补。

## 图片和视频分别消费

本地素材不是只供查阅。`resources/visual-library/README.md` 给出可执行入口：Overlay 的20种公开组件来自真实 React/CSS 源，参数、字号、位置与时间沿 registry；`visual-build` 输出 PNG/视频、可编辑源码 ZIP 与既有 studio 输入声明。19项支持透明层，FocusCard自带全屏底色，可实际放入本地视频。20项已分别验证改内容/参数、PNG、5秒动效、源码包及图/视频背景合成，这只是当前1920×1080测试输入的功能验证。`visual-compose` 显式用VP9 alpha解码叠加，普通media镜头不能替代透明合成。PNG可用于封面排版或作为实际生图参考，不能仅把文件名写进提示词。Table 场景的对象长度、条件与修整能力实际决定动作和分流；新的内容关系改场景，不把原示例套成万能流程图。

图片可以从连续场景选出最能解释本题的状态，或从包装组件出信息层，再与本题主物件合成；不要把无关流程截图当所有主题的方向图。现有 `resources/lemo-opuscar/mit-8814b84/styles/` 的材质、配色和原生工程继续通过原 opuscar 路线使用，不重复下载或把 43 个风格文件夹说成 43 个成熟模板。motion-explainer 的视觉隐喻表用于寻找“现实可见变化、熟悉系统、媒介材料本身”，其 Skia 引擎尚未安装，不冒称已接通。

图片提示按“主体和状态→构图/焦点→空间/光线→材质/颜色→文字与画幅→需要避免的具体问题”组织。参考图角色与文件一起交给实际图片工具；输出后真的看图，核形体、手物接触、身份、中文、图文主次、边缘与小屏裁切。封面沿 studio-publish 的现有供应方和逐图观察要求。

图生视频先定外观关键帧，再描述“谁怎样动作、相机怎样运动、状态怎样推进”。不要在运动提示里反复重建外观、塞满相互矛盾的运镜。代码动效把同一对象的形状、颜色、坐标与状态连续传递，连线/箭头表达真实关系。Match cut 借形状、方向或位置连接信息；不能只是同形无因果地连续炫技。

声音是动作和情绪的一部分。翻页、接触等现成音效只列候选，按实际画面与最终音轨实听；已有认可音轨不因换画面重做。镜头节奏由信息变化、动作与声音决定，不为固定秒数填空。

## 系列与镜头

方法取自一只桌子的 Table-VideoSOP（docs/09、连续 MG、镜头推进与转场、镜头剧本模板），沿本项目已有 visual-direction、brief、镜头合同与阶段交接执行，不另起一套 SOP。

系列先固定当前采用版：受众与内容承诺、画幅、字体/色彩/圆角、角色外观及可用姿态、光线与空间、配音/音乐和锁定哈希、参考的来源/区间/借鉴职责。各集换内容时保留这些约束；用户改变整体方向才修改相应依赖，不默认重配音或重画全部角色。

每段先用一句话写看点：谁对谁做了什么，观众因此理解什么。随后在既有镜头合同中写“源对象与依据→动作/接触→状态变化与可辨结果→下一镜接收对象”，关联真实音轨词点、素材路径和代码驱动入口。排序要看到原内容重新排列，筛选要看到条件及被保留/舍弃的对象，完成勾不能替代处理过程。画面应给出旁白之外的依据。

同章可让同一对象带着结果进入下一个构图，使用同一世界与相机；先定起点、结果和必要的交接/遮挡状态，状态可以共享，不按每几秒一张凑图。相机服务观察、比较与阅读；有空间关系时判断是否用分层/视差，正面同尺度比较时可以固定。不能把整页缩放、所有信息放进假窗口或不停漂移当作高级动效。

主动作、相机与接收方共同排时；动作可以在上一动作收尾时衔接，结果必须晚于条件与处理。阅读从字真正可读时计算，重点结果留出时间。上游“2秒构图、5字/秒、固定屏占比”等是作者诊断参照，按实际中文、小屏、声音与本题重新判断，不设为全项目硬指标。

新关系、高风险接触或跨镜连续性先做带最终声音的完整因果过程；同类过程已有效则复用，核本集差异后进入首版，避免机械重做样片。完整画面与音轨审阅沿项目现有 review，结构检查、静帧和渲染成功均不代替。系列复盘同时留下一个有效过程和具体失败/修改前后证据，按真实用户反馈和可比发布数据决定下集采用，不用教程热度保证自己的流量。

## 两种落地方式

- **已有模板升级**：保留全文、因果和有效动作；用本题物件替换通用图标，调整排版、材质、光线与运动层级。先对同一段做前后比较，核是否更清楚、更有看点，再扩全片。
- **模板外设计**：把视觉方向、真实资产和最难代表画面先做实；选择现有可编辑引擎。现有渲染/表演能力不足就记录具体缺口。独立方案不自动获得 make 资格，不借其他模板 ID 放行。

起步配方只是取舍参考，不是四个成熟模板。最终按目标观众核开头为何停下、过程为何继续、结尾兑现什么；画面与完整音轨沿现有审阅入口。素材齐、脚本合理、评分高和技术导出都不能替代观众接受度。高播放教程仅证明该方法受到关注，成品是否受欢迎仍需本题真实反馈。

来源及观察边界见 `docs/research/2026-11-17-视觉素材与审美/研究与采用.md`；真实目录由 `studio.py visual-assets` 返回。
